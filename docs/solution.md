## Baseline
An equal-weighted portfolio with quarterly rebalancing is used as the baseline strategy.

The initial portfolio value is set to $100,000. This value is chosen for convenient interpretation and visualization of the results and does not affect the relative performance metrics of the strategy.

Fractional shares are allowed throughout the experiment. This makes it possible to maintain the target equal weights precisely during portfolio construction and rebalancing, while eliminating distortions caused by share quantity rounding and residual cash balances.

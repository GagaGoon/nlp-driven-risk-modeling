# <mark style="background:#fff88f">Постановка задачи</mark>
## Тема
Применение языковых моделей для извлечения факторов риска из корпоративной отчетности и использование этих факторов при формировании инвестиционного портфеля
## Вопрос
Улучшают ли признаки риска, извлеченные из корпоративной отчетности с помощью NLP/LLM, прогноз будущего риска акций и позволяют ли они построить портфель с меньшей волатильностью или просадкой по сравнению с традиционными методами?
